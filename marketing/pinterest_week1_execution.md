## Execution Instructions

1. **Upload images** to Pinterest (or Tailwind). Lifestyle mockups are already sized appropriately.
2. **Copy title + description** from this document into the pin editor
3. **Select the correct board** from the 5 setup boards
4. **Add link** to the storefront: `https://everafterdigital.com/` (or live URL)
5. **Schedule** at 9am, 1pm, and 5pm (if 3 pins/day) or 10am and 3pm (if 2 pins/day)
6. **Enable Rich Pins** after domain verification

### Best Practices for Lifestyle Mockups
- Lifestyle shots work best as **standard pins** (not Idea Pins)
- Let the visual speak — minimal text overlay
- Pin description should include specific style keywords
- Tag the product category board for maximum relevance

### Fallback: If domain isn't verified yet
Use the Pinterest URL debugger to validate pins, and post with the developer's preview URL as the link temporarily.
